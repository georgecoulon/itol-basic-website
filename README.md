<h1 align="center">Simple HTML Website</h1>
A basic website created using HTML and CSS.<br /><br />

**Overview**

This website is used to practise basic HTML and CSS. 

It includes a navigation bar, with four pages (Home, About, Contact, Location).<br /><br />

**Repository Structure**

.

├── index.html           # Home page

├── about.html           # About page

├── contact.html         # Contact page with some validation

├── location.html        # Location page, including iframe

├── style.css            # Style sheet

├── script.js            # Script controlling toggle full screen and reload frame

**Requirements**

JavaScript

****Installation****

Clone the Repository

git clone https://github.com/georgecoulon/itol-basic-website.git
cd itol-basic-website

Alternatively, download the repository as a ZIP file and extract it to your preferred location.
